Internet vs World Wide Web

Internet

The Internet is a global network of interconnected computers and devices.

It provides the infrastructure on which services such as the WWW operate.

World Wide Web

The WWW is a system of interconnected web pages and resources that operates on top of the Internet.

It uses technologies such as HTTP, URLs and hyperlinks to access and connect web resources.

Difference

Internet WWW
Global network infrastructure System of web pages and resources
Uses TCP/IP for communication Uses technologies such as HTTP and URLs
Includes many services One service that operates on the Internet
Provides the network infrastructure Provides access to web information

Easy Example

Internet = Roads

WWW = Vehicles and traffic using those roads
