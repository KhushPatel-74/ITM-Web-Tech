Introduction to World Wide Web

What is WWW?

The World Wide Web (WWW) is a system of interconnected web pages and information that can be accessed using the Internet.

Web pages are connected through hyperlinks and can contain text, images, videos and other forms of content.

Characteristics of WWW

  • Uses hyperlinks to connect information.
  • Allows users to access information worldwide.
  • Supports text, images, videos and other content.
  • Works using the Internet as its underlying network.

History of WWW

  • WWW was created by Tim Berners-Lee.
  • It was developed at CERN in 1989.
  • The first website was hosted at info.cern.ch.
  • W3C was later established to develop Web standards.

Evolution of Web

Web 1.0: Mainly static and one-way information.

Web 2.0: Interactive websites and user-generated content.

Web 3.0: Focuses on semantic and personalized experiences.

Web 4.0: Described as a future intelligent and decentralized ecosystem.
