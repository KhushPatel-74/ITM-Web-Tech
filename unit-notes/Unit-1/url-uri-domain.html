URL, URI & Domain Names

What is a URI?

URI stands for Uniform Resource Identifier.

It is used to identify a resource on the Internet.

What is a URL?

URL stands for Uniform Resource Locator.

A URL identifies a resource and tells us where it can be found and how it can be accessed.

Example: https://www.itmbu.ac.in

URL Components

Example: https://www.itmbu.ac.in

  • https → Scheme / Protocol
  • www → Subdomain
  • itmbu → Second-Level Domain
  • .ac.in → Domain extension / TLD structure

URI vs URL

  • URI is a general identifier for a resource.
  • URL is a type of URI.
  • A URL provides the location and access method of a resource.

Domain Name

A domain name is a human-readable name used to identify a website or Internet resource.

Example: google.com

Domain names are easier for people to remember than numerical IP addresses.

Important Terms

  • TLD: Top-Level Domain
  • SLD: Second-Level Domain
  • Subdomain: A division of a domain
  • Registrar: Service through which domains can be registered
