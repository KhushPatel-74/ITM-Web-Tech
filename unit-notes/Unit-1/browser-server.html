Web Browser & Web Server

Web Browser

A web browser is software used to access and display web pages and other web resources.

Examples

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari

Functions

  • Sends requests to web servers.
  • Receives web resources.
  • Displays web pages to the user.

Web Server

A web server is a system that stores and delivers web resources to clients.

Functions

  • Receives requests from browsers.
  • Processes the request.
  • Sends the requested resource or response.

Client-Server Model

The browser acts as the client and the web server acts as the server.
