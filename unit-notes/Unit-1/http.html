HTTP Request & Response

What is HTTP?

HTTP stands for HyperText Transfer Protocol.

It is used for communication between a web browser and a web server.

HTTP Request

A request is sent by the client (browser) to the server when it wants a resource.

Main Parts

  • Request Line: Contains method, URI and HTTP version.
  • Headers: Provide additional information.
  • Body: Contains data when required.

Common Methods

  • GET
  • POST
  • PUT
  • DELETE

HTTP Response

The server sends a response back to the client after processing the request.

Main Parts

  • Status Line: Contains the HTTP version and status code.
  • Headers: Provide information about the response.
  • Body: Contains the requested content or data.

Important Headers

Request Headers:

  • Host
  • User-Agent
  • Accept

Response Headers:

  • Content-Type
  • Set-Cookie
  • Cache-Control
