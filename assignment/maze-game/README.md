# Maze Game

A browser-based maze game built with plain **HTML, CSS and JavaScript** (no frameworks or libraries). Made for the Web Technologies course assignment.

**Author:** Khush Patel

## Project structure

```
maze-game/
├── index.html    # Main page of the game
├── style.css     # Styling and layout
└── script.js     # Game logic
```

| File | Purpose |
|------|---------|
| `index.html` | The main page. It holds the structure of the game and links the CSS and JS files |
| `style.css` | Colors, layout and appearance |
| `script.js` | Game behavior and interactivity |

## How to run

1. Download or clone the repo:
   ```bash
   git clone https://github.com/KhushPatel-74/ITM-Web-Tech.git
   ```
2. Open the `assignment/maze-game` folder.
3. Double-click `index.html` to open it in your browser.

You can also use the **Live Server** extension in VS Code: right-click `index.html` and choose **Open with Live Server**.
