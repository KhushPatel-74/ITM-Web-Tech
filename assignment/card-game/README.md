# Card Game

A browser-based card game built with plain **HTML, CSS and JavaScript** (no frameworks or libraries). Made for the Web Technologies course assignment.

**Author:** Khush Patel

## Project structure

```
card-game/
├── index.html    # Main page of the game
├── game.html     # Game page
├── style.css     # Styling and layout
└── script.js     # Game logic
```

| File | Purpose |
|------|---------|
| `index.html` | The main page. Start here |
| `game.html` | The page where the game is played |
| `style.css` | Colors, layout and appearance |
| `script.js` | Game behavior and interactivity |

## How to run

1. Download or clone the repo:
   ```bash
   git clone https://github.com/KhushPatel-74/ITM-Web-Tech.git
   ```
2. Open the `assignment/card-game` folder.
3. Double-click `index.html` to open it in your browser.

You can also use the **Live Server** extension in VS Code: right-click `index.html` and choose **Open with Live Server**.
