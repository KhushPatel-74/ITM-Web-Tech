# Portfolio Website

My personal portfolio website, built with plain **HTML, CSS and JavaScript** (no frameworks or libraries). Made for the Web Technologies course assignment.

**Author:** Khush Patel

## Project structure

```
Portfolio/
├── index.html    # Main page of the portfolio
├── style.css     # Styling and layout
└── script.js     # Interactivity
```

| File | Purpose |
|------|---------|
| `index.html` | The portfolio page and its content |
| `style.css` | Colors, layout and appearance |
| `script.js` | Interactive behavior on the page |

## How to run

1. Download or clone the repo:
   ```bash
   git clone https://github.com/KhushPatel-74/ITM-Web-Tech.git
   ```
2. Open the `assignment/Portfolio` folder.
3. Double-click `index.html` to open it in your browser.

You can also use the **Live Server** extension in VS Code: right-click `index.html` and choose **Open with Live Server**.
