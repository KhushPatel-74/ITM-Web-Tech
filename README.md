See [`practicals/README.md`](practicals/README.md) for the full list of practicals.

## How to view the pages

1. Download or clone the repo:
   ```bash
   git clone https://github.com/KhushPatel-74/ITM-Web-Tech.git
   ```
2. Open any `.html` file in a browser (double-click it), or
3. In VS Code, install the **Live Server** extension, right-click an `.html` file and choose **Open with Live Server**.
